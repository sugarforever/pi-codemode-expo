# pi-codemode-expo 0.2.0

Add `withPiCodemodeExpo(config, { durableRoots })` for workspace-linked Pi Durable
1.3.0 packages outside `node_modules`. Supply absolute package directories; the
helper normalizes Windows separators, matches directory boundaries, and preserves
existing resolver composition. Unrelated imports retain their original routing.
Empty, relative and filesystem-root paths are rejected to prevent broad redirects.

Existing Metro configurations continue to work without changes. The native peer
remains `expo-quickjs@0.1.0`; this release does not change the engine or replay
fingerprint. It also includes the CI host-transport shutdown regression fix.

Experimental release. iOS simulator validation from 0.1.0 remains the mobile
baseline; Android, physical devices and mobile SQLite restart remain unverified.
