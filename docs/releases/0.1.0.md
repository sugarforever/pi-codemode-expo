# pi-codemode-expo 0.1.0 — experimental release

Native Expo QuickJS backend for Pi Codemode and Pi Durable 1.3.0, with Hermes
remaining the app runtime.

- Async tools, globals, output helpers and transactional store writes.
- Deterministic start/deliver/stop, seeded randomness, virtual UTC Date/performance
  clocks, ordered result delivery and native build fingerprints.
- Bounded native message/output/memory/stack/deadline handling.
- Pi Durable-owned journaling and real SQLite restart/replay verification.
- Metro helper keeps Pi Durable's identifier import out of the WASM launcher graph.
- Full native, adapter, SQLite and clean packed-consumer CI passes. Actual iOS
  Hermes smoke passes on Expo 58 / React Native 0.88.

```sh
npm install pi-codemode-expo@next expo-quickjs@0.1.0 @earendil-works/pi-codemode@1.3.0
```

Android, physical devices, mobile SQLite replay, and mobile reload acceptance
remain unverified. This release is for application integration and validation.
